# Cosm

A Mac app for working with your own Claude Code on your notes. Version 0.1.1, for Macs with Apple silicon (M1 or newer).

**[Download Cosm](https://github.com/emnl/cosm-releases/raw/main/cosm.dmg)**, open the file and drag Cosm into Applications.

## The first time you open it

Cosm isn't signed by Apple, so macOS stops it the first time:

1. Open Cosm. When macOS says it can't check it, click **Done**.
2. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Cosm.
3. Confirm with **Open Anyway** (and your password if asked).

After that it opens like any app, and it updates itself.
