# Cosm

A Mac app for working with your own Claude Code on your notes. Version 0.1.2, for Macs with Apple silicon (M1 or newer).

**[Download Cosm](https://github.com/emnl/cosm-releases/raw/main/cosm.dmg)**, open the file and drag Cosm into Applications.

## The first time you open it

Cosm isn't signed by Apple, so macOS stops it the first time:

1. Open Cosm. When macOS says it can't check it, click **Done**.
2. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Cosm.
3. Confirm with **Open Anyway** (and your password if asked).

After that it opens like any app, and it updates itself.

## What is new in 0.1.2

Cosm is now extended by packages: ask the agent for something Cosm doesn't do (a page that sums up your notes, keeping the cosm in git) and it builds it, then asks before switching it on; Settings → Packages switches them on and off. Cosm's own layout, its colours and the agent are packages too. Also: bold, links and headings can be edited by their markdown marks, which show as you type in them; clicking below a page puts the cursor at its end; Claude Code's own screen is larger, sharper and in Cosm's colours, and its page links can be clicked; choose the app icon in Settings; a quieter update notice.
